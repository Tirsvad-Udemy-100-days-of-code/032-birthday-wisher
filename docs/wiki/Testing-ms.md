# Ujian

🌐 [English](Testing) · [Dansk](Testing-da) · **Bahasa Melayu**

```bash
python -m pytest
```

![Larian ujian](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/032-birthday-wisher/raw/branch/main/docs/images/tests.png)

Ujian menggunakan sambungan SMTP palsu dan fail sementara. Ia tidak memerlukan rangkaian, `.env` atau kelayakan. Semakan pilihan:

```bash
python -m ruff check src tests
python -m mypy src tests
```

Dokumentasi API daripada komen Doxygen: `doxygen Doxyfile` (output dalam `docs/doxygen/`).
